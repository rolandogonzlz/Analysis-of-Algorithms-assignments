# Particle Swarm Optimization - Presentation I

## Build
```bash
make
```

## Run the benchmark demonstration
```bash
./pso
```

## Run the Wi-Fi case study
```bash
./wifi_pso
```

## Generate 30-seed swarm-size and inertia data
```bash
./batch_bench
```

## Compare PSO and K-means over 30 seeds
```bash
./compare_wifi
```

All outputs are written to `results/`.
